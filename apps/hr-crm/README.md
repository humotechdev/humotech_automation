# hr-crm

HR CRM HUMOTECH. React + TypeScript + Vite.

Сейчас здесь один экран — вход — и техническая основа под остальные:
маршрутизация, состояние сессии, единый клиент API и разбор ошибок.
Остальные разделы появятся вместе со своими экранами: пустой пункт меню
выглядит как работающий раздел, пока в него не ткнут.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit
npm test           # vitest, без браузера
npm run build      # tsc --noEmit + vite build
```

Модули собраны под Linux. На Windows команды запускаются через контейнер:

```bash
docker run --rm -v "D:/HUMO/apps/hr-crm:/app" -w /app node:22-alpine npm test
```

Dev-серверу нужен доступ к backend. Шлюз наружу не опубликован, поэтому
удобнее поднять сервер в той же сети Docker:

```bash
docker run -d --name humotech_crm_dev --network docker_humotech \
  -p 127.0.0.1:5173:5173 -v "D:/HUMO/apps/hr-crm:/app" -w /app \
  -e VITE_BACKEND_ORIGIN=http://gateway -e VITE_ORGANIZATION_CODE=DEMO \
  node:22-alpine npx vite --host 0.0.0.0
```

Файлы с Windows-тома контейнер не отслеживает: после правки нужен
`docker restart humotech_crm_dev`, HMR здесь не срабатывает.

## Переменные окружения

Образец — в `.env.example`. Секретов среди них нет и быть не может:
всё, что начинается с `VITE_`, попадает в собранный бандл.

| Переменная | Смысл |
|---|---|
| `VITE_API_URL` | адрес API, по умолчанию `/api/v1` |
| `VITE_ORGANIZATION_CODE` | код организации для входа |
| `VITE_BACKEND_ORIGIN` | куда dev-сервер проксирует `/api` |

### Почему организация — настройка, а не поле формы

Backend опознаёт человека по тройке «организация + почта + пароль»:
почта уникальна внутри организации, а не глобально. Спрашивать код
организации у кадровика незачем — установка CRM принадлежит одной
организации, и это свойство развёртывания, а не ввод пользователя.
Понадобится мультиарендность — поле добавится сюда, а не в макет.

## Вход

Сессионный, как у backend: Django ставит `sessionid`, изменяющие
запросы требуют заголовка `X-CSRFToken`. JWT здесь нет, токенов в
`localStorage` нет, пароль не сохраняется нигде. «Запомнить логин»
хранит ровно строку логина.

При запуске приложение спрашивает `/auth/me`, а не свою память: сессия
могла истечь или её мог снять администратор, пока вкладка была открыта.

## Регистрации нет

Учётные записи заводит администратор. Ни «создать аккаунт», ни входа
через соцсети, ни восстановления пароля на странице нет: последнее
обещало бы письмо, которого система не отправляет.
