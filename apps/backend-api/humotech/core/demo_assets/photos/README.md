# Пакет фотографий витрины

Пусто. Это нормальное состояние проекта: снимки берутся у фотобанка
Pexels по ключу, а ключ — секрет и в репозитории не хранится.

Пока пакета нет, карточки сотрудников показывают инициалы. Карточка
умеет и то и другое, и отсутствие снимка не считается поломкой.

## Как наполнить

С ключом:

    PEXELS_API_KEY=... python manage.py import_demo_photos

Из уже скачанных снимков (сеть не нужна):

    python manage.py import_demo_photos --from-dir <папка>

Имя каждого файла в папке должно начинаться с пола и возрастной группы:
`male-middle-07.jpg`, `female-young-02.jpg`. Пол берётся из имени, а не
угадывается по изображению: чужое лицо в карточке хуже, чем инициалы.

Обработка требует `Pillow` (`pip install pillow`). В боевые зависимости
он не входит: это инструмент разработчика, который запускают руками.

## Что получается

Каждый снимок обрезается квадратом по центру, уменьшается до 256×256 и
сохраняется в JPEG с качеством 82. Рядом пишется `manifest.json`: имя
файла, идентификатор Pexels, ссылка на источник, автор, дата загрузки,
пол, возрастная группа и табельный номер сотрудника, за которым снимок
закреплён.

JPEG, а не WebP: файловый сервис приложения принимает PDF, PNG и JPEG
(`humotech/files/storage.py`, таблица `MAGIC`). Снимок в WebP он
отвергнет по содержимому, и карточка не смогла бы его показать.
