# api-contracts

Единый источник правды по HTTP-контрактам между `backend-api` и его клиентами
(`employee-telegram-bot`, `hr-crm`, `face-terminal`).

## Правила

1. Контракт пишется **до** кода обеих сторон. Бэкенд реализует его, клиенты — потребляют.
2. Любое изменение поля = изменение здесь + отметка в разделе «История версий».
3. Ломающее изменение = новая версия файла (`*.v2.md`), старая живёт до миграции клиентов.
4. Контракт не содержит бизнес-логики и кода — только эндпоинты, схемы, коды ответов.
