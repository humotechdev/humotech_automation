## Проверка на изолированном стенде humotech_fix

- Шлюз: клиентский `X-Request-ID: spoofed-by-client` заменяется меткой шлюза — **после `nginx -s reload`**.
  Конфигурация шлюза смонтирована томом; правка файла без reload не действует.
- `/health/ready` возвращает `queues: {notifications_overdue: 0, exports_waiting: 0}`, `warnings: []`.
- Метка в строке `django.request` после последней правки фильтра на стенде **не перепроверялась** — покрыта
  регрессионным тестом.

## Остаточные риски и ручные шаги

1. При выкатке — `nginx -s reload` (или пересоздание) шлюза.
2. `/readyz` на домене API не проброшен шлюзом (отвечает Mini App); наружу смотрит `/health/ready`.
3. Полный прогон на `43d7441`: группы 1–12 — 3343 теста, 0 падений, 1 skipped (Alembic baseline, по замыслу). Группа 13 (оба файла пакета) в общем прогоне не дошла: фоновую задачу остановила система при нехватке памяти. Оба файла прошли отдельно вместе со связанными наборами.
