## Как гонять тесты

- Бэкенд: `scratchpad/audit1011/pt.sh <имя_бд> <файлы> -q` (образ `humotech/backend:test`, база
  `humotech_postgres`, для параллельных прогонов — разные имена БД).
- Временные сценарии вне исходников: `scratchpad/arch/run-scenario.sh <имя_бд> <файл>`.
- CRM: `docker exec humotech_crm sh -lc "cd /app && npx vitest run …"`; tsc —
  `D:\node.exe node_modules\typescript\bin\tsc --noEmit`.
- Бот и Mini App — в одноразовых контейнерах python:3.11-slim и node:20-alpine (исходники только на чтение).
- **Полный набор при нехватке памяти:** `scratchpad/audit1011/groups/run-groups.sh` — 12 групп по ~300 тестов
  строго последовательно, контейнер `--memory=1300m`, `--reuse-db`, junit на группу; сводка —
  `python groups/sum.py` (сверяет 3343 теста). Перед запуском: свободная память хоста (≥1,5 ГБ), нет
  осиротевших контейнеров `humotech/backend:test` (`docker ps`), ClamAV стенда можно остановить.
